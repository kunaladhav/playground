# React Playground

A hands-on React playground where I practice React concepts, hooks, patterns, and frontend problem-solving through small, focused assignments.

The goal of this repository is not to build one large application, but to **learn React by actually building, debugging, and experimenting with individual concepts.**

## 🎯 Purpose

This repository is my practical React learning environment.

Instead of only following tutorials, I use small assignments to practice:

- Understanding how React works
- Managing state and component communication
- Working with React Hooks
- Handling user interactions and events
- Working with APIs and asynchronous operations
- Debugging React applications
- Solving problems independently
- Building reusable React patterns

## 🧪 Assignments

The repository contains small React assignments designed to focus on one concept or problem at a time.

Examples include:

- State and rendering exercises
- Search and filtering
- Shopping cart functionality
- `useEffect` experiments
- Timer and cleanup exercises
- Keyboard and window event listeners
- `useRef` DOM access
- Programmatic input focus
- Click-outside detection

Each assignment is intentionally small so that I can focus on **understanding the underlying React behavior rather than hiding it behind a large application.**

## 🚀 Running Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd playground
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite.

## 📈 Learning Approach

The main focus of this repository is **active problem solving**.

For each assignment, I try to:

1. Understand the problem.
2. Think through the React concepts involved.
3. Implement the solution myself.
4. Debug mistakes and understand why they happened.
5. Refactor when necessary.
6. Document the important concepts and patterns learned.

The repository therefore represents my **learning process and practical React experience**, rather than a collection of polished production applications.
